## Что не меняем без согласования

Гипотезы, методы, состав сценариев, скрытые полезности, метрики, промпты и экспериментальную матрицу определяет команда. Исполнитель реализует спецификацию, не меняет её для получения желаемого результата. На dev допускаются согласованные исправления реализации с повтором затронутых сравнений. На test не подбираем настройки и не отбираем удачные seed. Результат любого корректно выполненного эпизода учитывается.
