# Сценарии

Это исторические входы пилота, которые ещё нужны тестам и pilot CLI. Описанные ниже E2/E3 относятся к прежнему плану; действующие 10 dev и 28 test находятся в `data/scenarios`, их матрица задана в `docs/experiments.md`. Эти файлы не входят в новый test.

- **Пилот:** `s0_01.json` ... `s3_01.json` и `s4_pilot.json` (5 разных случаев). Они используются для отладки агентов и инструментов.
- **Основной тест E2:** для семейств `s0`-`s3` файлы с суффиксами `_02`, `_03`, `_04` - 12 независимых исходных сценариев; без настройки промптов на них.
- **Задержки сообщений E3:** `s4_01.json`, `s4_02.json`, `s4_03.json` - три разных набора заданий. Каждый запускаем с задержками сообщений 1, 2 и 4 (значение `message_delay` в файле — по умолчанию).

`value` - скрытая эталонная полезность; она не передаётся LLM. Для сравнения режимов используйте одинаковые исходные JSON и сопоставимые seed окружения. В пилоте можно менять промпт, в основном тесте - нет.
